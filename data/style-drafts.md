# `style` — draft values for Max to confirm or overwrite

Claude Code was right to leave `style` blank rather than invent it: it's Max's characterisation, and
`commentary` (which is mine) already covers the reasoning.

But blank on all ten is also a dead field. So these are **drafts, not authored values** — two or
three words each, meant to be accepted, edited or binned on the fit page. Import them into a
`style_draft` column, or into `style` with a `source='suggested'` marker so a hand-edit is visibly
authoritative. Do not import them as if Max wrote them.
